## 判断

PR #12は close とする。

理由は以下の通り。

1. 変更対象が `CodexExec.result` のみであり、恒久的な製品仕様・運用仕様・実装変更ではない。
2. 内容は実行結果ログであり、mainへ取り込むより、TSK-021の判断記録として残す方が適切である。
3. PR作成から時間が経過しており、現行mainとの差分整合を取り直してまでmergeする優先度は低い。
4. mergeable false であり、古いPRを残し続けると中枢参照導入や後続作業の見通しを悪化させる。
5. ZIP除外方針を正式化する必要がある場合は、`CodexExec.result` ではなく、別TSKとしてdocsまたはscript仕様へ反映するのが妥当である。
