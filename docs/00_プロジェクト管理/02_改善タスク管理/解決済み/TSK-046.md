# TSK-046 旧横断運用mdを中枢参照スタブへ整理する

状態: 解決済み
優先度: High
主担当候補: ChatGPT(リポジトリ編集)
提案名: QSCOUT-LEGACY-OPS-DOCS-STUB-TSK046-01
解決日: 2026-05-10

## 背景

TSK-045で `Q-Scout-for-Spring` に `chatgpt-ops-rules` 中枢参照を導入した。

しかし、`docs/00_プロジェクト管理/05_横断運用規程/` 配下には、TSK-045以前の旧横断運用mdが多数残存していた。

これは `Spring-Tool-Development-Template` で実施した旧横断運用規程整理と同種の残件であり、共通運用ルール本文を各作業リポジトリへ重複保持しないという中枢参照方針と整合させる必要があった。

## 実施内容

1. `docs/00_プロジェクト管理/05_横断運用規程/` 配下のmdを棚卸しした。
2. Q-Scout側に残す文書と、共通運用ルール本文に相当する旧文書を分離した。
3. 共通運用ルール本文に相当する旧文書を `docs/90_アーカイブ/旧横断運用規程/TSK-046_QScout_旧横断運用規程/` へ移動した。
4. `00_運用ルール索引と実行ゲート.md` を中枢参照入口として整理した。
5. `chatgpt-ops-rules中枢参照方針.md` を更新し、Q-Scout側へ残す事項と重複保持しない事項を明確化した。
6. 改善タスク課題一覧をTSK-046解決済みへ同期した。
