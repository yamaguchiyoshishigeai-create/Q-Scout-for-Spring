# TSK-008 英語版アップロードボタンと説明系文言の整合を取る

- 区分: 多言語化
- 件名: 英語版アップロードボタンと説明系文言の整合を取る
- 状態: 確認待ち
- 優先度: 中
- 実施主体: ChatGPT(リポジトリ編集) / ユーザー(人)
- 関連箇所: テンプレート、メッセージ定義、フロントエンド表示制御

## 発端
修正点メモ、外部評価反映改善タスク

## 現状認識
送信ボタン文言はアプリ側 i18n により英語化済みである一方、従来のファイル選択欄はブラウザ標準UI表示に依存していたため、`?lang=en` でもブラウザ / OS のロケールによって「ファイルを選択」「選択されていません」と表示されることがあった。

このため、ファイル選択UIをアプリ側で制御するカスタム表示へ変更し、英語ページでは `Choose File` / `No file selected`、日本語ページでは `ファイルを選択` / `選択されていません` が表示されるようにした。

説明系文言の機械的なキー整合確認は、後続の `TSK-039 i18nキー整合チェッカーを実装する` に委ねる。

## 対応方針
主要画面と help の英日整合を横断確認する。

1. ChatGPT(リポジトリ編集) でテンプレートとメッセージ定義を確認する。
2. ファイル選択UIをブラウザ標準表示依存から、アプリ制御のカスタム表示へ切り替える。
3. 実画面確認、スクリーンショット確認、テスト実行を行い、問題がなければ解決済み化する。

## 完了条件
日本語・英語双方で主要導線が自然に読める。

特に英語ページで、ファイル選択欄が `Choose File` / `No file selected` として表示されることを確認する。
