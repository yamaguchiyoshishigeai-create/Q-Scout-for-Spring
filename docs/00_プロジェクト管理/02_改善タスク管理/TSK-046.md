# TSK-046 旧横断運用mdを中枢参照スタブへ整理する

状態: 未解決
優先度: High
主担当候補: ChatGPT(リポジトリ編集)
提案名: QSCOUT-LEGACY-OPS-DOCS-STUB-TSK046-01

## 背景

TSK-045で `Q-Scout-for-Spring` に `chatgpt-ops-rules` 中枢参照を導入した。

しかし、`docs/00_プロジェクト管理/05_横断運用規程/` 配下には、TSK-045以前の旧横断運用mdが多数残存している。

これは `Spring-Tool-Development-Template` で実施した旧横断運用規程整理と同種の残件であり、共通運用ルール本文を各作業リポジトリへ重複保持しないという中枢参照方針と整合させる必要がある。

## 目的

Q-Scout側に残っている旧横断運用mdを棚卸しし、共通運用ルール本文に相当する文書は `chatgpt-ops-rules` 参照スタブへ薄く整理する。

Q-Scout固有の業務仕様、実装仕様、公開サンプル評価、環境依存手順、Q-Scout固有の改善タスク運用はQ-Scout側に残す。

## 想定作業

1. `docs/00_プロジェクト管理/05_横断運用規程/` 配下のmdを棚卸しする。
2. 共通運用ルール本文に相当する文書を特定する。
3. Q-Scout固有情報を含む文書と共通運用ルール本文を分離する。
4. 共通運用ルール本文に相当する文書は、`chatgpt-ops-rules` への参照スタブへ整理する。
5. 旧本文を履歴として残す必要がある場合は、`docs/90_アーカイブ/旧横断運用規程/` 等へ移動する。
6. `00_運用ルール索引と実行ゲート.md` と `chatgpt-ops-rules中枢参照方針.md` からの導線を確認する。
7. 改善タスク課題一覧を解決済みへ同期する。

## 対象外

- Q-Scout固有の業務仕様・実装仕様の削除。
- 公開サンプル評価仕様の削除。
- Java / Spring Boot実装の変更。
- テストコードの変更。
- `chatgpt-ops-rules` 側の追加改定。
- APIM側またはportfolio側の横展開。
